# Memory Bank: Project Context

## SDD Workflow (OpenSpec 1.3+)
- **Active Changes:** Always look in `openspec/changes/` for the current `proposal.md` and `tasks.md`.
- **Source of Truth:** Refer to `openspec/specs/` for existing system behavior.
- **Templates:** Use files in `/templates` to scaffold new artifacts.
## Sync Instructions
After completing a task in `openspec/changes/<id>/tasks.md`, update `activeContext.md` to reflect progress.
